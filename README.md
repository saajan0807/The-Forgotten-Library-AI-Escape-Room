# 📚 The Forgotten Library – AI Escape Room

An interactive AI-powered escape room game built using **Python, Google Gemini API, and Gradio**.

Players explore a mysterious library, solve puzzles, discover hidden clues, unlock a secret drawer, collect an old key, and escape. Google Gemini acts as the AI Game Master, providing natural conversations, hints, and storytelling throughout the game.

---

## 🎯 Project Overview

The Forgotten Library demonstrates how Generative AI can be integrated with traditional Python programming to create an interactive gaming experience.

The project was developed in two versions:

### Version 1 – AI-Driven Implementation
- Gemini acts as the Game Master.
- Players interact through a Gradio chat interface.
- AI interprets player messages and generates responses.
- Game instructions and puzzle information are provided through prompts.

### Version 2 – Improved Implementation
- Introduces structured Python game-state management.
- Uses deterministic action recognition.
- Validates puzzle answers and player actions.
- Enforces puzzle-solving order.
- Prevents unauthorized actions and game-rule bypasses.
- Maintains inventory and game completion status.

## 🎮 Game Story

You are trapped inside a mysterious library.

To escape, you must discover clues and solve three puzzles in the correct order.

### Puzzle Challenges

| Puzzle | Correct Answer |
|---|---:|
| Bookshelf | 2 |
| Painting | 7 |
| Desk | 49 |

After solving all three puzzles, you must enter the secret combination:

**2749**

Once the drawer is unlocked, collect the **Old Key** and use it to escape the library.

### Game Progression

1. Explore the library.
2. Investigate the bookshelf.
3. Solve the painting puzzle.
4. Solve the desk puzzle.
5. Enter the drawer combination.
6. Unlock the drawer.
7. Collect the Old Key.
8. Escape the library.

---

## 🏗️ System Architecture

### Version 1

The initial version primarily relies on Gemini to interpret player messages and generate game responses.

### Version 2

The improved version separates AI-generated conversations from critical game logic.

**Main components:**
- Player Interface – Gradio
- Action Recognition – Python
- Game State Manager – Python
- Puzzle and Action Validation – Python
- AI Game Master – Google Gemini

This architecture improves consistency, reliability, and security.

---

## 🔒 Validation and Security

Version 2 includes several validation mechanisms:

- Rejects incorrect puzzle answers.
- Enforces the correct puzzle-solving sequence.
- Rejects incorrect drawer combinations.
- Prevents collecting the Old Key before unlocking the drawer.
- Prevents unauthorized actions.
- Prevents players from skipping required puzzles.

## 🚀 How to Run the Project

### Requirements

- Python 3.10 or later
- Google Gemini API key
- Internet connection
- Required Python libraries

### Setup Instructions

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project**

Open `AI_Escape_Room_Version_2.ipynb` using Google Colab or Jupyter Notebook.

**3. Configure the Gemini API key**

Obtain an API key from Google AI Studio:

https://aistudio.google.com/

Configure the API key securely in the notebook's setup section. Do not publish your API key in GitHub.

**4. Install dependencies**

Run the notebook's dependency installation cell.

**5. Execute the notebook**

Run all cells from top to bottom.

**6. Start playing**

Open the Gradio interface generated by the notebook and interact with the AI Game Master.
